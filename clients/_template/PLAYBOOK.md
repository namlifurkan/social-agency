# <Client> — client playbook

Fill this with the founder before the first post. The generic skills read it and it wins over them.

## Who and where
What the client is, its site/app, the accounts we post for.

## Audience and stories
Who watches, which topics travel, what never to say.

## Look
Wordmark, accent colour, palette, fonts (files in `fonts/`). Narrator voice id goes in `brand.json`.

## The close
How a reel ends (CTA line, badges, LINK IN BIO, or nothing).

## Our data (optional)
How the researcher reads the client's own data, read only.

## Carousel renderer (optional)
Leave empty to use HTML + headless Chrome (art-director default).

## Delivery
Output folder (e.g. `~/Desktop/<client>-video-posts/<post-date>-reel-<slug>/`), the txt files per platform, caption template.

## Publishing (optional)
Leave empty and nothing is published: the founder gets the files.

## Ledger
`LEARNINGS.md`: one row per post (date, topic, Test, Device, reach, follows).
