# okul.com.tr voice

Helpful, plain Turkish for parents. The site says "siz" on the homepage and tests, "sen" on lead
and compare pages; pick one per post (ask at setup which is default).

Copy from the site to borrow: "Hemen Okul Ara", "Aradığınız okulu vakit kaybetmeden bulun!",
"Okulunuzu tercih ederken veli yorumlarından yararlanın!", "Tamamen ücretsiz / 30 saniye / Okullar
seni arar".

The okul.com.tr voice assistant uses ElevenLabs "Derya" (`NNn9dv8zq2kUo7d3JSGG`, vault: Okul API
decisions 2026-10-10). A candidate narrator if the team wants the same voice; offer it at setup.
